Una shell por dentro.

Aprender cómo funciona una shell internamente.

19 de noviembre de 2026 · 3 min de lectura

En esta entrada vamos a hablar de un reto muy popular en la web CodeCrafters - build your own shell.

¿Qué es CodeCrafters?

CodeCrafters es una web que recopila diferentes retos de programación donde tienes que crear una herramienta desde 0 tú mismo. CodeCrafters te ofrece muy poca ayuda para que pienses las cosas por ti mismo y aprendas.

¿Cómo funciona?

Tiene decenas de retos en todos los lenguajes de programación populares. Una vez al mes suelen poner uno gratis, pero funciona con una suscripción que, aparte de darte la opción de hacer cualquier reto, también te da más agilidad a la hora de ejecutar tus tests en cada etapa.

Cada reto está dividido en fases con tests automáticos. La web tiene una CLI que puedes instalarte y utilizar para ejecutar los tests o enviar tu código para que el sistema lo compruebe y te dé acceso a la siguiente etapa.

Build your own shell

Es uno de los retos más populares y consiste en crear tu propia shell desde 0.

Una shell es el programa que interpreta lo que escribes en la terminal. Lee tus comandos, ejecuta programas y muestra sus resultados. Algunos ejemplos populares son Bash y ZSH.

Tu shell ejecutará un REPL, analizará comandos, generará procesos y mucho más.
