Cómo añadir tema claro y oscuro a tu web.

10 de noviembre de 2026 · 10 min de lectura

En esta entrada vamos a ver cómo podemos añadir un tema claro y oscuro a nuestra web. Es una funcionalidad bastante habitual que permite al usuario elegir la apariencia que le resulte más cómoda.

¿Qué necesitamos?

Básicamente, CSS y JavaScript. Utilizaremos CSS para definir los colores de cada tema y JavaScript para cambiar entre ellos. Además, guardaremos la preferencia del usuario para que no tenga que seleccionar el tema cada vez que visite la web.

El CSS

Lo primero es definir los colores utilizando variables CSS. De esta manera, podemos tener una paleta para el tema claro y otra para el oscuro sin necesidad de duplicar todos los estilos.

En nuestro caso hemos utilizado la paleta Solarized, que dispone de versiones Light y Dark. Para cambiar los colores, basta con modificar el atributo data-theme del documento.

La parte javascript

Con JavaScript nos encargamos de detectar cuándo el usuario pulsa el botón para cambiar de tema. Dependiendo del tema que esté activo, asignamos el valor "light" o "dark" al atributo data-theme.

También utilizamos localStorage para guardar la selección. Así, cuando el usuario vuelve a entrar en la página, recuperamos su preferencia y aplicamos automáticamente el tema correspondiente.

Por último, cambiamos el logo para que sus colores se adapten al tema seleccionado. Con estos pequeños cambios conseguimos una web más personalizable sin necesidad de utilizar ninguna librería externa.
